# 📖 Project Overview

The **AI Flower Classification System** was developed as part of the **DecodeLabs Artificial Intelligence Internship – Project 2: Data Classification Using AI**.

This project demonstrates the fundamentals of **Artificial Intelligence and Supervised Machine Learning** by training a **Decision Tree Classification Model** to classify Iris flowers into different species based on their measurements.

The application provides an interactive Streamlit dashboard where users can explore the dataset, visualize data, train the model, and predict flower species.

---

# 🎯 Project Objectives

- Load and understand the Iris Dataset
- Explore and visualize the dataset
- Split the dataset into training and testing sets
- Train a Decision Tree Classification model
- Evaluate model performance
- Predict Iris flower species
- Build an interactive Streamlit application
